### 🚀 Featured project

#### ✈️ [Trip Agent](https://github.com/prakhar28/ai-trip-planner)
An AI agent that plans trips that **actually fit a budget**. The trip planner is the excuse; the real point is the engineering around the agent.

- ⚙️ FastAPI + Redis queue + horizontally scaling **arq workers**
- 📡 Live progress over **SSE + Redis Streams**, with replay on reconnect
- 🛡️ Guardrails: turn, token and time budgets; **Pydantic-validated** final output
- 💰 Per-run token and USD **cost tracking**
- ✅ Golden-set **eval suite with a CI pass-rate gate**

`Python` `FastAPI` `Gemini` `Redis` `Postgres` `React` `Docker`
