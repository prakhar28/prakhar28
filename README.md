### 🧠 About me

I'm an **AI Engineer and Senior Full-Stack Engineer** with ~7 years of shipping products end to end, from mobile and web frontends to the backends and LLM pipelines behind them.

I care about the unglamorous parts that make AI products trustworthy: **deterministic guardrails around probabilistic models, eval suites that gate every change, streaming UX, and knowing what each request costs.**

```yaml
role:      AI Engineer · Senior Full-Stack Engineer
focus:     LLM agents, multi-stage AI pipelines, evals, full-stack product engineering
frontend:  React, React Native, TypeScript
backend:   Python (FastAPI), Java (Spring Boot), Postgres, Redis
ai:        Gemini, tool calling, structured outputs (Pydantic), golden-set evals
education: M.S. Computer Science (Seattle University) · M.S. Information Technology (Trine University)
location:  New York / New Jersey · open to remote, NYC and the Bay Area
```
